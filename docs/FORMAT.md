# Формат `.sdmod`

`.sdmod` — это обычный **zip-архив**, который можно открыть любым архиватором (расширение можно заменить на `.zip`).

```
my-outfit.sdmod
├── mod.json                      # метаданные (необязательно, но рекомендуется)
├── preview.png                   # превью (необязательно; .png/.jpg/.jpeg)
└── RedirectorData/
    └── Characters_New/
        ├── Shirt.perm.bin
        └── Shirt.temp.bin
```

Пути внутри `RedirectorData/` повторяют путь в папке игры:
`...\SleepingDogsDefinitiveEdition\RedirectorData\Characters_New\Shirt.perm.bin`.

## mod.json

```json
{
  "formatVersion": 1,
  "id": "my-outfit",
  "name": "My Outfit",
  "version": "1.0.0",
  "author": "you",
  "description": "Новая рубашка для Вэя",
  "category": "Characters",
  "homepage": "https://example.com",
  "preview": "preview.png"
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `formatVersion` | нет (по умолчанию 1) | Версия формата. Загрузчик откажется открывать моды с большей версией. |
| `id` | да* | Уникальный идентификатор: `a-z 0-9 . _ -`, до 64 символов. *Если не задан — строится из `name`. |
| `name` | нет | Отображаемое имя. |
| `version`, `author`, `description`, `category`, `homepage` | нет | Информация в карточке мода. |
| `preview` | нет | Имя файла превью в корне архива. |

## Правила разбора архива

1. `mod.json` ищется в корне архива или в единственной вложенной папке (тогда она считается корнем).
2. Если в пути есть папка `RedirectorData` (в первых уровнях), всё до неё отбрасывается, остальное копируется в игру как есть.
3. Иначе, если есть папка `Characters_New` (или опечатка `Character_New`), файлы внутри неё (с подпапками) попадают в `RedirectorData/Characters_New/`, всё лишнее снаружи игнорируется.
4. Иначе («голые» файлы) всё кладётся в `RedirectorData/Characters_New/`. Если все файлы лежат в одной общей папке-обёртке, она отбрасывается, а загрузчик предупредит об этом.
5. `mod.json`, `preview.*`, `readme*`, `license*`, `changelog*` в корне — служебные, в игру не копируются.
6. Небезопасные пути (`..`, абсолютные, `C:`) → архив отклоняется.
7. Требование FileRedirector: каждому `*.perm.bin` нужен `*.temp.bin` (пусть пустой). Загрузчик предупредит, если пары нет.

## Как работает включение/выключение

* Импортированные моды лежат в `Data/Mods/<id>/` рядом с exe (portable).
* **Включение** копирует файлы в папку игры. Если файл уже существовал (оригинал или чужой мод) — он уходит в `Data/Backups/` и возвращается при выключении.
* `Data/state.json` хранит, какой мод владеет каждым файлом, поэтому порядок включения/выключения нескольких модов безопасен.
